# Задание 2. Подготовка базы знаний

## Формирование базы знаний

Для формирования базы знаний был взят открытый фандом по звездным войнам.

1. Перейти в директорию [Task2](./) и установить все зависимости из файла [requirements.txt](./requirements.txt)
```
cd Task2
pip install -r requirements.txt
```

2. Запустить скрипт выгрузки страниц с ключевыми персонажами, планетами, технологиями, организациями и событиями.
```
python.exe .\download_and_clean.py
```

3. Запустить скрипт замены ключевых терминов.
```
python.exe .\replace_terms.py
```
